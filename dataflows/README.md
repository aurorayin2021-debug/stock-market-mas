# 数据接入与处理

`news_masking.py` 读取 CMIN 预处理新闻，用模型识别公司、股票代码和产品名称，再通过程序替换原文中的对应片段。中文新闻的目标公司替换为“公司 A”，其他公司从“公司 B”开始，产品从“产品 1”开始；英文新闻则使用“Company A”、“Company B”和“Product 1”。其他公司和产品的编号只在同一标题内有效，不代表跨标题的对应关系。未提及目标公司的标题不会添加公司 A。

从项目根目录运行。程序会读取项目根目录的 `.env` 文件，其中设置 `MODEL_BASE_URL`、`MODEL_API_KEY` 和 `MASK_MODEL`。已有的系统或终端环境变量优先于 `.env`。不要将真实密钥写入 `.env.example` 或提交到 Git。`.env` 只在本地保存，不是加密文件。

例如，试跑一只美股的一天的前 5 条：

```powershell
python -m dataflows.news_masking --market US --stock AAPL --date 2021-01-04 --target-name Apple --ticker AAPL
```

处理完整文件可在命令后添加 `--limit 0`；指定其他样本数量用 `--limit 数量`。中国新闻使用 `--market CN`，并将其余参数替换为对应股票文件夹、公司名和代码。每条标题调用一次模型，会产生 API 费用。结果保存在对应 `news/masked/股票文件夹/`，试跑文件名包含样本数量；已有结果不会被覆盖。原始和预处理文件不会改变。

结果每行保存去标识后的 `text` 字符串和原来的 `created_at`。模型可能漏掉名称或识别错误，需要人工抽查；仅替换名称不能保证完全消除历史信息泄露。文件路径和日期仍用于程序内部对齐，后续传给分析模型时应只传允许看到的内容。
